# Project Overview

## Project

**Isla Nublar HomeLab**

## Primary Host

**NUBLAR-CORE**

## Purpose

Isla Nublar HomeLab is a documented cybersecurity and infrastructure lab built inside a restored legacy Gateway tower.

The project combines:

- Legacy computer restoration
- Modern PC hardware integration
- Custom chassis engineering
- 3D printing and fabrication
- Virtualization
- Networking
- Linux and Windows administration
- Active Directory
- Cybersecurity testing
- Monitoring and logging
- Storage and backup
- Automation
- Technical documentation

The project is intended to function both as a practical learning environment and as a technical portfolio demonstrating the full process of designing, building, securing, operating, troubleshooting, and documenting a small-scale infrastructure environment.

## Design Philosophy

The project prioritizes:

1. Reliability
2. Expandability
3. Security
4. Maintainability
5. Documentation
6. Reasonable power consumption
7. Adequate cooling
8. Educational value
9. Portfolio value
10. Jurassic-inspired visual identity

## Physical Design Concept

NUBLAR-CORE will use a legacy Gateway tower as its physical enclosure.

The chassis will retain recognizable retro-computer characteristics while being restored and adapted for modern hardware.

Planned visual elements include:

- Preserving the Gateway identity where practical
- Repainting selected exterior surfaces
- Jurassic-inspired detailing
- Custom 3D-printed dinosaur skeletal elements
- Potential stealth repurposing of legacy drive bays for modern I/O or monitoring

All cosmetic changes must remain subordinate to airflow, electrical safety, maintenance access, and component serviceability.

## Technical Direction

The final HomeLab is expected to support workloads including:

- Proxmox VE
- Linux servers
- Windows Server
- Windows client systems
- Active Directory
- Docker containers
- Cybersecurity monitoring
- Centralized logging
- SIEM experimentation
- Isolated cyber-range systems
- Infrastructure monitoring
- Storage services
- Development environments
- Automation tooling

Specific hardware and services will be selected only when justified by the requirements of each phase.

## Documentation Standard

Meaningful changes should document:

1. Current state
2. Goal
3. Action performed
4. Result
5. Problems encountered
6. Troubleshooting and solution
7. Design decision
8. Reason for the decision
9. Supporting photographs, diagrams, measurements, or configuration
10. Next step

The repository should preserve failures, redesigns, and trade-offs as part of the engineering record.

## Current Status

**Current Phase:** Phase 0 — Legacy System Documentation & Chassis Survey

The Gateway chassis has been acquired and photographed in its original assembled state.

The next stage is to identify and inventory the existing system before disassembly, then safely empty and measure the chassis.

## Historical Note

NUBLAR-CORE was originally planned around a Rosewill THOR V2 chassis.

The project was later redesigned around a legacy Gateway tower, expanding the scope to include restoration, custom fabrication, mechanical compatibility analysis, airflow engineering, and 3D-printed modifications.

The earlier design remains preserved in Git history.
