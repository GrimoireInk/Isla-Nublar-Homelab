# Changelog

All meaningful architectural and build changes to Isla Nublar HomeLab are recorded here.

## 2026-11-08 — Gateway Sleeper Redesign

### Changed

- Replaced the planned Rosewill THOR V2 chassis with a legacy Gateway tower.
- Expanded NUBLAR-CORE from a conventional HomeLab build into a retro sleeper restoration and custom fabrication project.
- Added legacy-system documentation, chassis surveying, restoration, airflow engineering, and 3D-printing work to the project scope.
- Reorganized the project roadmap so hardware selection follows physical chassis measurement rather than preceding it.
- Established Phase 0 as Legacy System Documentation & Chassis Survey.

### Planned

- Document the original Gateway hardware before teardown.
- Inventory labels, wiring, expansion cards, drives, motherboard, and PSU.
- Safely empty and photograph the chassis.
- Measure modern hardware compatibility.
- Develop the Jurassic-inspired exterior design after airflow and serviceability requirements are known.

## Earlier Planning

The repository was originally created around a budget-conscious HomeLab planned for a Rosewill THOR V2 chassis. That history remains preserved in Git so the design evolution is visible.
